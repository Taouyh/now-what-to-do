# 现在做什么

纯 HTML、CSS、JavaScript 的碎片时间任务助手。选择时间和环境，立即得到适合当前状态的小任务；数据只保存在浏览器 `localStorage`。

直接双击 `index.html` 即可运行，无需 Node.js、npm 或服务器。

## GitHub Pages

1. 在 GitHub 创建仓库并上传全部文件。
2. 打开 **Settings → Pages**，选择 **Deploy from a branch**。
3. 选择主分支和 `/ (root)`，点击 **Save**。
4. 访问 `https://你的用户名.github.io/仓库名/`。

功能包括随机推荐、任务执行与完成记录、今日统计、目标进度、任务筛选、自定义任务和目标、JSON 导入导出、深色模式。

用户数据仅保存在当前浏览器的本地存储中；建议定期导出 JSON 备份。清除浏览器数据、更换浏览器或设备后，不会自动同步恢复。

## 数据保护

- 首次使用且主数据为空时初始化默认内容；已有数据无法读取、解析或迁移时，停止保存并显示保护界面，不自动重置。能够读取的原始主数据及计时内容可以分别导出为文本留存。
- 保存失败会持续提示，主数据恢复到操作前的内存快照，任务或目标编辑框保留输入以便重试。完成记录保存失败不会清除活动计时；计时清理失败会保留已保存的记录，并在重新加载后重试清理。
- 支持现有 v2 备份及旧版备份。导入先校验并确认替换目标、任务、记录、偏好、主题和备份中的其他主数据；保存成功后同步界面。单独存储的活动计时不随 JSON 备份导入或导出。
- 旧版迁移保留原有目标、任务、历史记录和其他字段，仅补充缺省数据、缺失记录 ID 及默认任务。不会补造旧记录的开始或结束时间；已有主数据的迁移不在启动时自动回写。

## 数据安全验证

自动测试使用隔离数据，需要 Node.js；本次以 v24.18.0 执行，无需安装 npm 依赖：

```powershell
node --test tests/data-safety.test.cjs
node tests/browser-data-safety.cjs
```

第二条命令使用本机 Chrome 无头模式、新建临时配置和独立浏览器上下文，不访问日常浏览器配置。Chrome 不在默认位置时，可通过 `CHROME_PATH` 指定可执行文件。

测试范围、实际结果和剩余限制见 [数据安全验证记录](docs/data-safety-validation.md)。
