# 空档启动：第二阶段方向草案

日期：2026-11-01。输入：[研究报告](../../research/market-2026-11-01/REPORT.md)、[产品规则](../../rules/product.md)、用户本轮四项需求。

状态：方向、低保真流程和测试任务已拟定。用户于 2026-11-01 明确要求按本方向制作产品文档与 Figma 可交互 UI/UX，方向与范围据此确认，进入第三、四阶段；参与者测试仍未执行。以下为产品提案，不代表当前应用已实现。

## 1. 建议聚焦的方向

**把一段空闲，变成自己想做的事的一小段进展。**

主文案候选：**少纠结，马上做一点。**

解释文案：**按你现在的空档，选好一件做得了、停得下、下次接得上的事。**

优先人群：已有想读的书、想练的技能或未完成的小作品，空下来却反复选择或重新准备的人。用户完全没想法时，也应能从少量默认活动直接开始。第一轮以 5–30 分钟空档验证，这只是范围假设。

核心单位是一段可执行的行动，包含：

- **此刻可行**：时间、环境和材料允许；准备与收尾也占用空档。
- **第一步具体**：例如“翻到你上次记下的第 42 页，先读一页”。未知进度时不生成虚构页码。
- **停止点清楚**：例如“到点就在当前段落末停下”，不承诺一定完成某章或某件作品。
- **下次接得上**：结束时可选留一句位置或下一步，再次打开时用于推荐。

例子：用户有 15 分钟，书在手边。推荐“继续读自己的那本书”，先打开书签位置；按约 1 分钟准备、10 分钟阅读、1 分钟留位置的模板安排，并留余量。若进入和准备已耗时，按剩余空档缩短阅读；模板估时需测试，不能写成保证。

## 2. 为什么优先验证它

| 候选方向 | 可提供的价值 | 判断与取舍 |
| --- | --- | --- |
| 更多随机活动与惊喜 | 降低找灵感成本 | 可作默认内容；容易进入不断换一项的浏览循环，暂不作为主定位 |
| 展示“省了多少时间” | 让结果可感知 | 作为价值证据；数字本身不产生价值，需先有可信对照 |
| 按空档推进个人活动，并保留接续点 | 同时减少选择、准备、重新进入的成本 | 本轮主假设；需要与普通随机、情境推荐＋第一步比较，检验增加收尾与续做是否值得 |

这是一项服务组合和聚焦场景的差异化假设，不能据此宣称“唯一”或“竞品做不到”。可积累的价值是用户自己的活动、可用的接续记录和经过验证的启动模板；目前尚未形成壁垒。

## 3. 把四项需求变成验收问题

| 用户需求 | 原型应提供什么 | 怎样判断有价值 |
| --- | --- | --- |
| 找到不同的方向 | 空档约束、个人活动、第一步、停止点和接续点贯通 | 相比简化方案，实际启动更快、可控收尾更多，新增记录负担可接受 |
| 强调节省决策时间 | 先测本次选择用时与真实启动用时，再建立个人对照 | 同一用户、匹配场景比较；不以点击开始代替真实开始 |
| 充分利用空闲时间 | 把准备和收尾计入预算；允许缩小行动或选择休息 | 活动适配空档，用户认可这段时间；休息不记为失败 |
| 愿意接着用 | 下次无需重新想从哪里开始；看见自己已经做过的小进展 | 出现新空档时主动复用，而非靠提醒、连续签到或奖励驱动 |

## 4. 时间价值怎样表达才可信

区分三个量，原型测试使用同一计时口径：

1. **选择用时**：从打开入口到用户确定本次活动；“开始”按钮可作确认的代理信号。
2. **启动用时**：从打开入口到真实开始活动，包含选择和准备。由观察或用户明确确认记录；无法确认就记未知。
3. **活动与收尾用时**：真实开始后做了多久、是否在空档内妥善停止。无法观测时只能标注用户自报。

选择快但迟迟没开始，不算核心目标达成。默认活动的首次体验与已有接续记录的回访体验分开统计；录入、准备和留记录的成本均不能隐藏。

**尚无个人对照时**，可以展示实际可测的“本次选择用时”，附在可选回顾中，不新增阻挡启动的页面。不能展示“为你节省了 5 分钟”。

**建立匹配对照后**，节省量定义为 `对照启动用时 − 本次启动用时`。用同口径的多次记录做个人摘要，显示样本数、观察期限及是否包含自报数据；无匹配记录就不估算，结果为负时也如实保留。研究阶段先验证，不纳入首版必须实现的界面。

示意计算：对照 180 秒、本次 45 秒，差值 135 秒；这是算式示例，不是实验结果。不能把活动时长、倒计时或点击速度当作节省时间，也不能将每次差值无条件相加为累计收益。公开宣传采用试验结果时须标明样本、口径与局限。

## 5. 再次使用的理由

目标是“下次有空，想到它能帮我开始”，不是增加用户待在应用里的时间。

- **首次即时得到结果**：不用先建立完整活动库；少量默认模板足以试用。
- **有自己的东西可继续**：活动后可选记“停在第 48 页，下次接着读”。可以略过、修改、删除；不要求写总结。
- **回访更省事**：有记录且适合当下才推荐续做，用户可改做别的；上次的剩余事项不自动变成义务。
- **反馈具体且轻**：例如“这周你记录了 3 次阅读”，仅依据实际记录；不虚构进展或效率分数。
- **偏好由轻反馈修正**：“现在不方便”只影响当下；“以后少推荐”才改变长期偏好。反馈可跳过。

不加入核心路径：信息流、排行榜、连续打卡惩罚、自动催促、强制通知。用户休息或退出仍是有效选择。

## 6. 本轮建议范围与交付

原型只验证：可选空档输入、单项可行建议、具体第一步与停止点、按剩余时间缩小行动、拒绝与无结果、可选接续记录、下次推荐。计时可选，选择后即可离开应用行动。
