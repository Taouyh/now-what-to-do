# 续做入口澄清

用户反馈：“记下一步”不知道记录谁的下一步，希望更简洁突出。

## 实现

- 反馈状态写“本次已记录”；入口改为有边框的纸色按钮“记下次起点 · 读书”，其中名称来自刚完成的记录快照，不使用新的推荐名称。
- 按钮可访问名称为“为「读书」记录下次起点”。长名称省略显示，完整名称保留在可访问名称和 title。
- 展开后显示并关联真实 label：“读书：下次从哪继续？”。读取与保存仍通过原 taskId，仅更新该活动说明，取消和关闭不写入。
- 编辑状态收紧桌面推荐区域的间距，为输入和保存/取消留出书页空间；窄屏沿用可滚动布局。三语言及深色样式复用现有翻译和纸色按钮，没有新增图片或字体。
- PRD/INTERACTIONS 同步澄清；不修改计时、历史记录或存储格式。
