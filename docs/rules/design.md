# Design rules

Established from market research on 2026-11-01; detailed UI work starts in stage 4.
- Show one primary action, one suggestion, and its first step clearly.
- Keep time and context easy to adjust without a mandatory questionnaire.
- Make rejection and stopping as understandable as starting; allow interruption without blame.
- Use progressive disclosure for activity management, history, and advanced controls.
- Use readable Chinese, visible keyboard focus, adequate contrast, and comfortable touch targets.
- Avoid forced animation, advertising delays, and guilt-based messages on the path to action.
