# Development rules

Established from market research on 2026-11-01; framework selection remains stage 5.
- Keep the core recommendation usable offline, without registration or a network round trip.
- Filter impossible activities before ranking; explain a recommendation in plain language.
- Protect existing activities and records during changes; keep backup and recovery available.
- Make skip, stop, interruption, and restart behavior explicit and verifiable.
- Measure time to an actual first action; a timer click alone is not success. Collect research data only with consent.
- Add dependencies or AI only when a measured user benefit justifies their cost.
