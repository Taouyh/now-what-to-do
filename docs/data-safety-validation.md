日期：2026-10-19。修复前基线：`2eace87`。仅处理初始化、迁移、持久化异常及 JSON 导入；未修改推荐算法、分页、悬浮窗、统计和 HTML 注入处理。

## 实际修改

- `validateData()` / `migrateData()` / `seedDefaultTasks()`：先验证，再复制并进行保留式迁移。不删除旧目标、任务或记录，不重映射原关联，保留未知字段；缺省内容只做补充。生成缺失记录 ID 时避开已存在的 ID。
- `loadData()` / `protectData()`：只有缺失键或空字符串按首次使用初始化。非空损坏内容、未知新版本、不可读取存储或无效活动计时均进入保护界面，禁止后续持久化；可导出能够读取到的原始字符串。保护界面不提供自动重置或覆盖导入。
- `save()` / `setTimerState()` 及其调用点：捕获写入、删除异常，显示持续错误提示，只有保存成功才继续关闭编辑框或显示成功。主数据失败后恢复操作前的内存快照及偏好界面；活动计时写入失败时保留原存储状态。
- `finishTimer()` / `renderTimer()` / `restoreTimer()`：完成记录保存失败不清除活动计时；完成记录已保存而计时删除失败时不再次显示同轮计时，重新加载后按完成 ID 清理，避免重复落账。缺失任务信息的计时保留原文并进入保护模式。
- `validateImport()` / `applyImport()` / 文件读取事件：校验 v1/v2 备份，确认后以一次主数据写入提交；成功后同步时间、环境、电脑偏好、主题和推荐页。取消会清除候选备份；异步读取旧文件的结果不能替换后选文件。活动计时键不参与导入。
- 导入后若界面同步异常，尝试恢复导入前存储和内存；如果恢复也失败，停止后续写入并提供导入前原文导出，不显示导入成功。

## 数据格式与回退

继续使用 `whatToDoData` 和 `activeTimer`，主数据格式仍为 v2，无新增数据库、存储键或运行依赖。

无版本号或 `version:1` 的旧数据转为 v2；保留原有对象字段，只补缺省偏好、主题、记录 ID 和尚未注入的默认内容。旧记录可以只有 `date` 与 `minutes`，不会生成其原本没有的 `startedAt`、`endedAt` 或 `completedAt`。

已有主数据只在内存中迁移，首次加载不会自动回写。后续明确保存或确认导入时才写入迁移结果。失败时原存储字符串保留；无法兼容的内容进入保护模式供原文导出，不被静默丢弃。此前版本已经删除且没有备份的数据无法由本次修复重建。

普通操作保存失败会回退内存变更，编辑框输入保留，可在恢复存储后再次提交。导出“当前数据备份”包含当前内存中已接受的数据，不包含未提交表单，也不包含活动计时。

## 尚存限制

- 配额不足、禁止存储和回退失败通过故障注入验证；未实际填满磁盘、修改真实浏览器设置或触碰用户浏览器配置。
- Chrome 覆盖的是本轮数据安全场景，未做全站人工交互、视觉、多浏览器、真实下载权限或系统休眠验收。
- 多标签页并发覆盖仍未解决；`localStorage` 的两个键也没有跨键事务。本轮仅保证先保存完成记录，再清理计时，并利用完成 ID 处理失败重试。
- 原始内容被浏览器禁止读取时无法导出，需用户恢复存储权限。损坏内容需人工核查修复；应用不会自行重置。导入回退写入也失败时，本地可能保留新备份，导入前原文只在当前页面内存中保留，应先导出再关闭页面。
- HTML 注入风险按本轮限制保留；通过结构校验的备份不代表其文本已经过安全转义。
- 其他功能没有因为本轮测试通过而被视作已验收。系统休眠是否计入有效用时仍待确认，本轮未改变计时规则。
