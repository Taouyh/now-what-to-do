# 现在做什么 · 产品需求说明（C 版任务与日历 + B 版其余页面）

日期：2026-11-04。状态：用户最新确定任务书册与日历采用 C 版，其余页面仍采用 B 版。本文为当前产品与交互的统一依据，供阶段 4 评审和后续实现使用。选定方案不等于原型全部验收，也不代表功能已经上线。阶段 5 尚未启动。

## 1. 产品目标与适用人群

帮助有空闲时间、却在“现在做什么”上犹豫的人，快速选出一件当下能做的个人活动，并立刻开始。重点服务已有兴趣、学习内容或日常活动，希望减少选择负担的人。

核心路径为：查看一个推荐 → 按需调整时间与条件 → 开始专注 → 结束并记录 → 得到下一项推荐。用户也可以自己选任务、管理活动或直接退出，不要求写总结、连续打卡或完成整项长期任务。

“任务”是可反复进行的活动，如读书、画画、经济学入门课程；“完成本次”表示结束一段专注并记录投入，不自动把任务标记为永久完成或从列表删除。

## 2. 本次方案决策与依据

采用 **C 版任务与日历 + B 版其余页面**：任务列表铺满左右书页，内容超出时翻页；添加表单按需展开卷轴。C 日历左页为任务目录、右页为记录明细，两侧独立分页。现在做、时间与条件、专注和设置延续 B 版。B 版任务与日历保留为历史备选。

| 决策 | 当前规则 |
| --- | --- |
| 任务布局 | 每张书页 5 项，一次双页展示最多 10 项；更多内容通过页底翻页 |
| 添加任务 | 右页「＋ 添加任务」展开右侧卷轴；默认书页不常驻表单 |
| 编辑任务 | 悬停仅变色；点击纸条直接编辑；移除铅笔和二次“编辑”步骤 |
| 行内开始 | 仅显示播放图标；悬停提示“开始”，与纸条编辑点击相互独立 |
| 活动说明 | 添加和编辑均保留可选说明，可修改、清空 |
| 完成后条件 | 先清空四项“当前条件”，再生成下一项推荐；本次时间继续保留 |
| B 版保留范围 | 首页、时间与条件、专注及结束、设置；任务书签与自己选进入 C 版任务，日历书签进入 C 版日历 |
| 历史备选 | B 版常驻添加任务页和 B 版日历保留作对照，不进入正式导航 |

冲突处理顺序：用户最新明确要求 → 本文与 [交互契约](INTERACTIONS.md) → 对应模块选定的 B/C 原型 → 旧书版后续修订 → 已有 v1.3 的未被替代能力。早期独立移动端探索、默认不计时、拒绝原因问卷、强制收尾页等不属于当前要求。

绿色版已经确认但尚未迁入旧书的流程，列入第 11 节缺口，不能仅因新画板未展示就视为取消。

## 3. 信息架构与页面职责

| 入口 | 页面职责 | 主要内容 |
| --- | --- | --- |
| 现在做 | 减少选择，快速启动 | 单项推荐、时间、当前条件、开始、换一件、自己选；进行中显示专注书页 |
| 任务 | 管理与手选个人活动 | 双页纸条列表、翻页、添加卷轴、直接编辑、删除确认、独立播放 |
| 日历 | 查看已记录的投入 | 今日日期、次数与用时汇总、按任务分组、每次记录及只读明细 |
| 设置 | 管理偏好及数据 | 语言、深浅外观、备份导出、备份导入与替换确认 |

四个入口位于书本右上沿，使用实体书签形态及图标、简短中文名称。任意时刻仅当前入口高亮；选中书签更亮并略高，未选中仍可辨认。日历当前指“今天的记录”，不因此新增月历、排期、提醒或截止日期。

## 4. 页面与业务规则

### 4.1 现在做与推荐

- 左页保留“今日篇章”、章节编号、植物版画及“从这一页开始。”；右页突出当前任务和开始操作。
- 一次只展示一项任务。支持换一件、自己选和调整条件，不增加新的推荐起始页。
- 时间选项按 10 / 15 / 20 / 30 / 60 分钟及自定义排列（2026-11-06 用户反馈：移除 5，新增 20）；兼容读取旧备份的 5 分钟。自定义为 1–1440 分钟整数；未输入或仅空白时，关闭卷轴、按回车或离开页面默认回到 10 分钟；非空无效输入继续提示错误。25 分钟不新增为预设，也不据此重定首次默认时间。
- 时间与条件使用高亮纸质卷轴。时间预设点击即生效并收起；自定义有效输入即时应用，可按回车收起，不显示时间确定键。当前条件独立多选，在同一轮内关闭再打开保留选择。
- 2026-11-06：自定义时间不显示常驻范围提醒。非空无效输入立即弹出黑底白字“请输入 1–1440 的整数”，有效输入清除提醒；回车校验失败保留草稿，禁止以无效时长开始。空白退出或回车仍默认 10 分钟。
- 2026-11-06：当前条件隐藏可见复选方框，整行可点击。浅色主题选中文字加深、加粗；深色主题提高文字亮度、加粗。保留键盘 Tab/空格操作及焦点提示，条件的确定键保持。“自己选”悬停不显示竖排下划线，以底色变化反馈；续做输入框移除发亮外轮廓，以底色和边框颜色表示悬停/焦点。
- 当前条件为：方便使用电脑、方便听音频、方便出声、可能随时被打断。它们描述当下环境，不等于任务自身的要求。
- 首次进入或重启原型时，四项当前条件默认全部未选；同一轮选择后关闭卷轴、切换书签再返回仍保留。正常完成后再按既定规则清空，不在每次进入首页时清空。
- 时间与条件选择后的收起采用约 240ms 的连续卷回并淡出，约 10ms 后无额外过渡返回首页；取消原先约 620ms 的三段串联停顿。此为原型时序设定，实际帧率需浏览器验证。
- 电脑、音频、出声按任务要求筛选；未勾选不表示“全部条件满足”。可能被打断时优先推荐可中断活动，保留 v1.3 的优先规则，不将“不便中断”擅自改为绝对排除。
- 换一件沿用本轮不重复规则；本轮耗尽提供“重新看看”与自己选。没有符合条件的活动时提供调整条件，不偷偷放宽限制。无任务时提供添加入口，不把评审样例自动灌入用户库。
- 有其他可行任务时，结束后避免立即推荐刚结束的一项；只有一项或无匹配时，沿用明确的单项/空结果规则。

### 4.2 专注与结束

- 开始后进入正常双页专注书页，立即计时。任务与计时为核心，说明按需展开；无说明时不显示空入口。
- 暂停不计投入；继续恢复原任务、已累计时长及说明展开状态。
- 到点显示等待状态，不自动记录、结束或认定任务完成。等待时间不计入投入；可以继续追加或结束并记录。
- 追加沿用已有规则：原计划时长的一半，按分钟四舍五入且至少 1 分钟；例如 25 分钟追加 13 分钟。原计划时长与追加量分别保留。
- 离开专注页去任务、日历或设置时保留进行中任务，并提供返回专注入口。已有专注时点另一任务的播放，应返回当前专注，不能覆盖任务或重置计时。
- 专注保存独立快照。期间修改或删除活动，不改写已开始的名称、说明与时长，也不改写已有历史记录。
- 正常结束：记录本次实际投入 → 清除进行中状态 → 清空四项当前条件 → 按清空后的条件推荐下一件。手动结束、暂停态结束、到点结束均遵守这一顺序；不清空已选时间、任务要求或活动说明。
- “完成后清空”只发生在本次确实结束并进入下一次推荐时；暂停、切换书签、返回专注、关闭条件卷轴均不触发该重置。
- 恢复异常中断的计时继续沿用确认恢复流程，离开期间不虚增投入。放弃本次不记录，不进入正常结束反馈；返回首页提示“本次用时不会计入今天”，约 30 秒消失。
- 正常结束后在 B 版首页就地显示续做反馈，不强制填写。无操作时保留；可展开、修改或清空本次活动的下一步说明，保存只更新对应任务的说明；取消不修改任务。保存、取消、关闭或开始下一次后隐藏反馈，不使用短暂提示替代此流程。原任务已删除时，不把说明写入另一项任务。
  2026-11-06 追加界面反馈：入口显示“记下次起点 · 刚完成的活动名称”，采用有边框的完整按钮；展开显示“活动名称：下次从哪继续？”，明确对象是刚结束的活动，而非当前推荐。保持上述保存语义。

### 4.3 C 版任务书册与分页

- 每页 5 条、每组双页 10 条；按现有任务顺序排布，左右页连续编号。默认进入第一组书页。
- 页底上一页、下一页翻动一组双页，显示当前页码和总页数；首页不能向前，末页不能向后。禁用按钮不触发导航。
- 任务增加时增加页数，不把整本书向下拉长。末组不足 10 项时保留余白，不复制任务填满。
- 点击任务名称或纸条空白处，直接展开该任务的编辑卷轴；悬停不改变右页内容、不留下持续选中状态。
- 播放图标独立开始任务，不同时打开编辑；可见提示与可访问名称均为“开始”。
- 新增成功后定位到新任务所在书页。编辑保存后回到原书页；取消或关闭返回原列表位置。
- 删除后按剩余任务重新连续分页；末组删空则回到最近有效页；全部删空显示空书页和添加入口。原型已覆盖固定 15 个任务槽位内的重排与空态，通用数据量仍须在实现阶段验证。

### 4.4 添加、编辑与删除卷轴

2026-11-06 按钮视觉追加：编辑表单的保存/取消/删除、添加表单的添加/取消均采用现有保存/添加的棕色皮革渐变主按钮样式，字号与高度一致；取消和删除确认的行为不变。

| 字段/操作 | 规则 |
| --- | --- |
| 任务名称 | 必填；去除首尾空白后不能为空，错误就地显示且保留其他草稿 |
| 需要的条件 | 可选：必须用电脑、必须听音频、需要出声、不便中断；四个图标独立选中与取消，悬停解释 |
| 活动说明 | 可选多行文字，表达要做的内容或下次继续的位置；可以清空 |
| 添加 | 新开卷轴使用空草稿；成功保存活动、收起卷轴并定位新任务 |
| 保存修改 | 名称有效且有变更时才写回；无变更直接收起，不重复写入或显示成功提示 |
| 叉号、取消、切换页面 | 不提交草稿；再次展开读取已保存内容 |
| 删除 | 进入确认，说明“只删除此任务，已有记录保留”；确认后删除，取消返回编辑并保留原草稿 |

卷轴覆盖右页、底层适度压暗，左页上下文仍可见。编辑卷轴右侧突出“保存”“删除”按键；不再提供额外“编辑”入口。关闭与保存采用轻量卷起/收回表达，不能等待动画才能开始下一操作。长说明不能撑开书本外框，可在文本编辑区域内部滚动；任务和记录目录使用分页。

任务编辑与添加卷轴采用和当前条件相近的短动效：打开时从透明收拢态一次展开，关闭时一次卷回并淡出，各为 240ms Ease Out，加约 10ms 状态切换。跳过两段卷起中间态；保存或删除后的书页定位不再额外淡入。删除确认及取消保留现有业务逻辑。

### 4.5 C 版日历书册

- 左页为今天日期、次数、实际用时和任务目录，每页最多 5 个任务分组；右页初始显示查看提示，点击任务后显示各次记录，每页最多 4 条。
- 2026-11-06：右页常规列表用较小文字、自适应行高完整显示每页最多 4 条，不出现内部滚动条。展开记录的长明细仍可滚动，窄屏采用页面自然滚动，不裁切内容。
- 同轮补充：明细展开前后保持记录列宽和最小行高，长内容滚动不显示占宽滚动条。左页目录参照任务纸条，仅显示活动名；次数和用时在右页保留。
- 左页目录与右页明细独立翻页，页底分别显示页码和首末边界。切换任务从该任务明细第一页开始；翻动左页目录后清除不可见任务的明细，回到查看提示。
- 记录超过一页时增加书页，不撑高整本书。保留记录展开与返回专注入口；分页不改变汇总数据。
- 每条记录显示时间段及实际用时；2026-11-06 用户反馈：起止时刻统一显示至分钟（HH:mm），跨日仍带日期，原始时间戳与实际用时精度不变。点击整行展开计划、暂停、追加信息。同一时刻最多展开一条；查看历史不允许修改历史用时。
- 汇总基于记录数据，不因分页、折叠或删除原任务而减少。无记录时显示空态，不补造次数或时长。

### 4.6 设置与数据保护

- 保留中文、英文、日文与深浅外观，重新进入设置保留选择。旧书主题的色彩和材质仍应服务于清晰阅读。
- 导出备份由真实应用产生文件；导入先说明替换范围，确认后执行，取消不改变数据。不能把原型的“恢复成功”当成真实备份验证。
- 任务、说明、偏好和记录属于不同数据对象；删除任务不等于删除历史，草稿不等于保存数据。
- 同一段专注结束只生成一条记录；重复点击或恢复后重试不能重复计入。记录失败时不得显示已保存成功或丢弃可恢复状态。

## 5. 状态与数据口径

| 对象 | 必要含义 | 生命周期 |
| --- | --- | --- |
| 任务 | 稳定标识、名称、四项要求、可选说明 | 添加/保存后持久化，删除不级联历史 |
| 当前选择 | 本次时长与四项环境条件 | 本轮保留；正常结束后条件清零，时长保留 |
| 编辑草稿 | 正在输入的名称、条件、说明 | 保存前不影响任务；关闭丢弃 |
| 专注会话 | 任务快照、计划、累计投入、暂停、追加、状态 | 单一进行中会话，恢复需核实时间 |
| 历史记录 | 会话标识、任务快照、起止时间、实际/计划/暂停/追加用时 | 结束成功后保存，只读且防重复 |
| 展示状态 | 书页索引、打开的卷轴、选中的记录、悬停 | 不作为任务业务数据；不得触发保存 |

实际投入不等于计划时间，也不等于起止时间差；暂停、到点等待和未经确认的离开时间不能混入投入。日历沿用现有统计口径；原型中的任务数量、日期和统计均为评审样例，不能作为真实使用结果。

## 6. 视觉、适配与可访问性

- 清晰立体的摊开旧书是主体；暖黄/象牙旧纸、深棕文字、红棕皮革、低亮度黄铜细节，环境深棕且虚化。
- 保留中央书脊、纸页弧度、叠页厚度、接触阴影和适量纹理。文字、图标和按钮区域清楚，避免纯白卡片、绿色主色、密集装饰。
- 正式 B/C 页面统一为 1600×1000；C 任务、空态、添加/编辑/删除卷轴及卷起状态均已对齐。背景填充、书本与书签使用相同尺寸和位置，避免切换时重新缩放、背景跳动。产品验收要求整本书、四个书签和页底操作在目标桌面窗口内完整可见，不能依赖浏览器纵向滚动找到按钮。
- Figma 使用 Fit width and height / scale-down 评审；这只是预览缩放，不代表应用已完成响应式适配。小窗口和系统放大时须兼顾可读字号与点击区域，不可只无限缩小整图。移动端布局尚未选定。
- 标题延续 Noto Serif SC，数字及页码用 EB Garamond，操作文字复用既有字体。主操作突出，按钮保留默认、悬停、按下反馈。
- 键盘应能访问书签、翻页、播放、卷轴字段及关闭操作；焦点清楚，图标有名称，关闭后回到触发入口；错误不只靠颜色表达。减弱动态效果的用户可跳过翻页/卷起动画。

## 7. 范围与非目标

本轮覆盖单项推荐、时间与条件、任务增删改、专注计时及恢复、今日记录、偏好与备份。以已有 v1.3 能力为基础整合 C 版布局，不增加账号同步、付费、信息流、排行榜、打卡、月历排期、任务优先级、复杂项目管理或 AI 自动拆解。

首次默认活动库、用户会节省多少时间、是否提升长期复用均未验证。不会把示例任务当作已批准的默认库，也不显示未经测量的“省时”指标。

## 10. 效果验证

主要观察从打开产品到真实开始活动的时间，包含选择和准备；“点击开始”只是代理信号。辅助观察换一件次数、是否能理解条件、编辑误触、分页查找成本、记录负担，以及有空时是否主动复用。

首次添加、已有任务回访、未开始及退出分开记录。60 秒内开始可作探索目标，不是已验证承诺。没有个人匹配对照时，不计算省下的分钟数。参与者测试尚未运行。
