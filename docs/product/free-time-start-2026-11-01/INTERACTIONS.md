# 点击与状态变化契约 v1

**历史交互稿：** 自 2026-11-04 起，以用户选定的 [C 版书册交互契约](../book-c-2026-11-04/INTERACTIONS.md)为准。下文默认不计时、独立收尾等探索路径不再作为当前需求。

本表描述目标产品行为；Figma 的预设演示与真实实现边界在设计交付文档说明。标识用于连接 PRD、Figma 页面名和交互验证记录。所有返回都保留本轮已确认的空档与限制，除非用户明确重新开始。

| 页面/状态 | 点击目标 | 变化与目标 | 返回/数据规则 |
| --- | --- | --- | --- |
| H：首页 | 5/15/30 分钟、不确定 | 选中样式与预算改变，仍留首页 | 不触发推荐；不确定不猜预算 |
| H：首页 | 帮我选一件 | R：一张默认可行行动卡 | 无需建库；带入空档 |
| H：首页 | 当前条件 | C：条件页，修改环境、材料等 | 应用后带回首页；取消不提交 |
| H / R | 自己选 | M：可行活动短列表 | 保留上下文 |
| H / R / M | 休息一下 | X：休息结束页 | 不新增未完成任务 |
| R：行动卡 | 开始这一步 | A：活动进行页，计时默认关闭 | 仅记录开始意图 |
| R：行动卡（2026-11-02 修订） | 详情 / 收起 | 同一活动展开 / 收起准备与收尾细分 | 标签与第一步保持；各活动独立返回原卡，不重置空档 |
| R | 现在不合适 | J：拒绝原因页 | 返回仍为该卡 |
| R | 修改空档 | H：空档选项 | 已耗时需计入剩余预算 |
| J：拒绝原因 | 时间不够 | R5：更短行动与预算 | 不额外要求长表单 |
| J | 东西不在 / 现在不想 | R2：本轮另一项可行建议 | 排除本轮拒绝项，临时反馈不改长期偏好 |
| J | 以后少推荐 | P：偏好已调整反馈 | 可撤销；继续换另一件 |
| J | 跳过原因，换一件 | R2：另一项建议 | 不要求解释 |
| J2：连续拒绝 | 缩小到一步 / 自己选 / 休息 | R5 / M / X | 保留继续换选自由 |
| J2 / EPOOL：建议耗尽 | 继续换一件 / 缩小后仍无可行项 | EPOOL：说明本轮已没有新建议 | 不反复展示本轮已拒绝项；材料缺失时不重新推荐需该材料的短行动 |
| EPOOL | 调整条件 / 自己选 / 休息 / 重新选一轮 | C / M / X / H | 只有明确重新选一轮才允许重新进入选择 |
| E：无可行结果 | 缩小到一步 | R5：仅在确有可行短行动时出现 | 不得隐式解除限制 |
| E | 调整条件 / 自己选 / 休息 | C / M / X | 无结果不是错误或失败 |
| C：条件 | 条件选项 | 选中反馈；应用前为草稿 | 返回取消草稿 |
| C | 应用条件 | H 或 E，取决于可行性 | 原型提供普通与无结果两种预设场景 |
| M：我的/手选 | 某项活动 | 对应行动卡 | 显示真实用户记录或明确默认模板 |
| M | 添加自己的活动 | N：活动编辑页 | 名称必填、第一步可选 |
| N：活动编辑 | 保存，名称为空 | N-error：名称错误提示 | 保留其他输入，不能保存空名称 |
| N | 保存，有名称 | 对应个人行动卡 | 原型用示例填入演示 |
| A：活动进行 | 开启计时 | T：计时进行 | 可选，不影响是否能做活动 |
| T：计时进行 | 暂停 / 继续 | T-pause / T | 暂停不自动完成 |
| T | 时间到了（演示场景） | T-end：到点提示 | 实际产品由计时触发；原型场景入口在评审导览 |
| A / T | 被打断了 | I：中断状态 | 计时暂停；可继续或结束 |
| I：中断 | 继续 / 今天到这里 | A 或原计时状态 / F | 不记为失败 |
| A / T / T-end | 今天到这里 | F：可选接续记录 | 不预填虚构本次进展 |
| F：接续记录 | 输入区域 | 编辑内容 | Figma 用预填示例状态模拟输入 |
| F | 保存并结束，有内容 | D：已保存反馈 | 下次从保存位置续做 |
| F | 保存并结束，空内容 / 直接结束 | D0：未留位置的结束反馈 | 不新增或覆盖旧记录 |
| D / D0 | 看看本次回顾 | V：选择用时反馈 | 数字标注示例；不宣称已省多少时间 |
| D | 下次有空（演示入口） | H2：有接续位置的回访首页 | 是评审入口，不是自动召回或通知 |
| H2：回访 | 接着做 | R-own：个人活动卡 | 重新确认当前条件适合；可换一件 |
| M / H2 | 编辑接续位置 | F-edit：已有记录编辑页 | 保存替换原记录，取消保留 |
| F-edit | 删除记录 | Q：删除确认 | 明示仅删接续记录，不删活动 |
| Q：删除确认 | 取消 / 确认删除 | F-edit / M0：活动仍在、接续记录为空 | 不再展示旧位置 |
| P：偏好反馈 | 撤销 | 原行动卡及恢复反馈 | 不保留本次长期偏好修改 |
| X / D0 / V | 回到现在 | H：首页 | 显式新一轮；已保存个人资料保留 |

评审要求：所有看起来可操作的控件都有对应连线或明确的禁用反馈；不能只给主按钮连线。导航、取消、空输入、无结果、暂停、中断、删除与撤销均应可检查。

已交付的 Figma 页面、实际点击演示与输入/计时边界见 [设计交付](../../design/free-time-start-2026-11-01/DELIVERY.md)。已选中的导航与已经填入的示例可保持当前状态；长期偏好在本次会话中影响后续推荐，撤销恢复。

2026-11-02 文案更新：“开始这一步”→“开始”，“保存并结束”→“保存”，“不留记录，直接结束”→“跳过”，“今天到这里”→“结束”。表内旧称保留作功能对照，实际界面以短文案为准。推荐页新增 6 组“详情 / 收起”交互。
