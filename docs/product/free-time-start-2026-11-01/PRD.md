## 定位与用户

**少纠结，马上做一点。** 按当前空档，为用户选一段做得了、停得下、下次接得上的个人活动。优先服务有兴趣或未完成活动、空下来却迟迟无法开始的人；没有活动库的人可直接使用默认建议。休息是有效结果。

首轮聚焦 5–30 分钟空档，是待验证的场景边界。差异化在空档适配、个人活动、具体第一步、停止点和接续记录的组合体验；免注册、隐私、单项推荐均为基础要求，不宣称独有。

## 确认范围与待验证假设

| 已确认的产品要求 | 待验证的效果或参数 |
| --- | --- |
| 可跳过设置、一次一个可行建议、允许手选和退出 | 能否在 60 秒内真实开始、减少多少启动时间 |
| 明确第一步和停止点，准备收尾计入空档 | 模板估时是否合适，5–30 分钟是否最佳范围 |
| 可选记录，下次根据记录续做 | 用户是否愿意留记录，是否因此主动复用 |
| 拒绝原因可跳过，区分当下不方便和长期偏好 | 两次拒绝后提供简化出口是否有效 |
| Figma 原生可编辑页面、点击连线和交互说明 | 原型示例不能证明推荐、计时和存储已上线 |

不纳入本轮：账号同步、付费、信息流、连续打卡、自动通知、AI 自动拆解、完整项目管理。现有应用实现与本提案分开，不改写已有用户代码。

## 用户故事与验收标准

| ID | 用户故事 | 验收标准 |
| --- | --- | --- |
| R01 | 有空时，我能快速得到一件事 | 首次不用建库或注册；可选 5/15/30 分钟或不确定；选项有选中反馈；主按钮进入单项行动卡 |
| R02 | 我知道现在该做哪一步 | 默认显示简短活动名、一句动作、时长/材料/可中断标签和停止点；准备与收尾细分通过“详情”展开，未知时间不猜预算 |
| R03 | 不合适时，我能及时调整 | 点击“现在不合适”显示原因；时间不足缩小、材料不在本轮排除、暂不想做本轮跳过；长期少推荐单独操作且可撤销 |
| R04 | 剩余时间改变后，我仍能做一点 | 更新剩余时间后按剩余预算重新评估；不放宽明确限制；没有合适项时显示无结果并允许调整、手选或休息 |
| R05 | 我能自己选或加自己的活动 | 手选使用简短活动列表；可选添加名称与第一步，名称空时解释错误；保存后回到行动卡；允许取消 |
| R06 | 我能离开界面去行动 | 点击开始进入轻量活动页；计时默认关闭、可选启用/暂停；离开页面不算放弃；计时结束不自动标记完成 |
| R07 | 被打断时，我能停下或继续 | 被打断进入明确状态，计时暂停；继续回活动页；结束进入可选记录；不得标记失败 |
| R08 | 我能让下次更容易继续 | 收尾输入可跳过；保存成功反馈后展示接续入口；旧位置与本次输入有区别；允许编辑与删除确认 |
| R09 | 我能休息并随时结束 | 休息直达结束页，不强制计时、写总结或下次回来；提供回到首页入口 |
| R10 | 我能理解时间反馈 | 可选回顾展示本次选择用时；按钮意图不当作真实启动；无匹配个人对照时不计算“省下时间” |

## 行为与数据边界

- 空档预算从用户确认可用时间起扣除已流逝时间；切后台后按实际流逝时间重新判断。未知时间仅提供可随时停止的短动作。
- 可行性优先于兴趣或续做；个人活动优先但不强制，记录不完整时不生成虚构位置。估计有余量，不保证完成。
- 默认模板明确材料条件，使用“需一本书”等标签，不假设已保存用户的个人书籍。
- “现在不想”不永久屏蔽；“东西不在”仅影响本轮；“以后少推荐”改变偏好且可撤销。连续两次拒绝后增加缩小、手选和休息出口。
- 正在进行、暂停、结束是不同状态；结束计时不能推断完成任务。刷新恢复属于后续开发验收要求，Figma 只用预设状态演示。
- 接续记录为用户自愿提供，保存确认后才可用于下次推荐。删除需说明删除对象并确认；取消保留原记录。
- 本轮 Figma 的文本输入与时间变化通过明确标注的示例状态模拟，不连接真实存储或设备计时。评审数据均为示例。

## 信息架构与交互契约

2026-11-02 根据用户批注精简界面：活动名使用“读书”等直白名词，主按钮使用“开始”“保存”等短动词；默认每页仅保留必要动作与状态。材料、时长和可中断性用标签组件表达，细分说明按需展开；删除范围与错误原因仍须清楚。此规则优先于早期线框中的长文案。

首页“现在”承担启动入口；“我的”承担个人活动与接续记录，避免首页变成长清单。回顾在活动结束后按需查看。详细状态、点击结果及回退规则见 [交互清单](INTERACTIONS.md)。

移动端作为完整演示载体（390 × 844），桌面提供首页/推荐并排布局示意（1440 × 1000）；移动端优先是本轮设计取舍，不是技术平台决策。

## 成功指标与验证

主指标为从打开入口到真实开始活动的时间，含选择和准备；选择确认仅是代理信号。分别报告首次配置、回访、未开始和未知数据，休息单列；记录与收尾成本纳入整体体验判断。

辅助指标：60 秒内真实开始比例、跳过次数、空档内妥善停止比例、留记录负担、出现相关空档时的 7 天无提醒主动复用。省时量为同一用户匹配场景的对照启动时间减本次启动时间；无对照不推算，负值也保留。

[测试任务与探索决策线](../../prototype/free-time-start-2026-11-01/TESTS.md)继续有效；小样本不证明商业需求。尚无实验结果，不承诺“节省 X 分钟”或已达成留存提升。
