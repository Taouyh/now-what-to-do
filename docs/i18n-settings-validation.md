# 三语言与紧凑设置页验收

日期：2026-10-23。本文记录本地验证结果，尚未发布线上。

## 实现

- 设置第一项新增原生名称按钮「简体中文 / English / 日本語」，支持鼠标与键盘操作，以 `aria-pressed` 表示当前选择。
- 设置卡片最大宽度从 640px 调整为 520px，减少行内留白与按钮尺寸，保留备份和恢复的简短说明。窄屏语言选项可换行，英文和日文导航避免文字断行。
- `i18n.js` 保存明确的界面文案字典、语言协商与占位符格式化。静态标记与动态文案调用分开处理，不扫描或替换用户内容。
- 翻译覆盖开始、活动列表与编辑、当前条件、计时、执行记录、设置、通知、删除／导入／结束确认、数据校验与恢复界面，以及占位文本和无障碍标签。
- 首次按浏览器语言列表匹配中文、英文或日文地区变体，不支持的列表回退为英文。手动选择保存在 `preferences.language`，备份导入与导出沿用该字段。缺少此字段的旧数据无需迁移写入，仍跟随浏览器；不支持的备份语言值会被拒绝。
- 语言改变后立即更新界面及文档 `lang`、标题；保留活动名称、说明、历史数据、未知字段和进行中的计时。存储失败回滚语言与选中状态。
