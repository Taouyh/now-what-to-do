# 今天页逐次记录简化提案

2026-10-25。用户确认本产品图后，已将简化形式接入应用源码；本目录仍作为使用示例数据的独立产品预览。

保留活动汇总。活动展开后，每次执行直接用一行呈现“时间段 + 实际用时 + 更多信息”，取消每条记录的六项字段面板、重复序号和内层折叠箭头。常规时间段显示到分钟；精确到秒的起止时间和计划、追加、暂停等信息收到“更多信息”，零追加或零暂停不占用展示空间。应用中不足一分钟的记录仍显示秒数，跨日保留日期，缺失时间不推算。有效用时仍保留真实分钟、秒值，不用时间差覆盖已保存时长。

更多信息通过省略号进入，以两行补充精确时间与计划等信息；未知的旧计划与追加仍明确显示未知/未记录。一个活动只展开一项补充信息，点击另一条时收起前一条。按钮具备 aria-expanded 和 aria-controls，支持键盘激活、Escape 收起并恢复按钮焦点。维持活动卡片 10 秒自动收起，操作更多信息时重新计时；自动收起时关闭补充信息，并在键盘焦点位于内容区时将焦点移回活动摘要。页面切换及重绘清理计时，不改写原始记录或存储。截图参数 capture=1 只用于独立预览冻结收起，不属于正式应用功能。

示例数据中第三次执行沿用用户截图中的 20:04:48–20:19:33、有效 14 分钟 44 秒、计划 10 分钟、追加 5 分钟和暂停 0 秒；其余为合成示例。预览不读取或写入应用数据。
