# 添加活动：聚焦面板与图标条件

2026-11-02，依据用户两条批注修改当前 v1.3 迭代原型。

[设计与悬停示例](https://www.figma.com/design/I0Q7mK9wBhOqcuruuklkIf?node-id=99-521) · [体验添加交互](https://www.figma.com/proto/I0Q7mK9wBhOqcuruuklkIf?node-id=49-256&starting-point-node-id=49%3A256)

- 空白、已填写、名称错误、条件配置四个添加状态统一使用米白面板、绿色边框和阴影；页面其余部分模糊、弱化。点击背景或 Esc 取消，鼠标移出面板不会误关表单。
- 四个条件改成一排 48 × 48 图标，分别表示电脑、音频、出声、不便中断。可多选，点击后用浅绿底和绿色边框表示选中，再点取消。
- 鼠标进入图标时显示完整中文提示，移开隐藏；提示只读，不承载点击操作。原型提示定位在图标旁并避让右侧边缘；不是逐帧跟随指针。实际前端可在指针旁定位，并设置提示不截获鼠标事件。
- 条件不再需要展开，名称输入、错误提示、添加与取消保留。原展开态由 530px 缩至 322px，四条件区域由 200px 缩至 48px；原未展开态为 318px，现为 322px。
- 同一表单填写和校验时保留选择；重新发起添加会清空上次条件与悬停状态。原型不执行真实活动存储或计时。

已回读 16 个图标实例的原生 hover / leave / click actions，验证提示透明度 0→1→0 和独立选中/反选；四个表单的背景模糊、面板高亮、添加与取消连接完整。已核对添加页与悬停示例截图。浏览器实点和参与者测试未执行，应用代码未修改。
