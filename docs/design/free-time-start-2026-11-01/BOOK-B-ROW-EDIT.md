# B 版 · 点击任务纸条直接编辑

2026-11-03。用户指出原来的“点击选中、铅笔修改”不符合目标交互，本轮以以下规则覆盖前述说明。

- 鼠标进入任务纸条时只改变纸条底色与边线，右页添加表单保持不变；移出恢复。
- 点击整条纸条（含名称及空白区域）直接展开该任务的编辑卷轴。
- 去掉铅笔图标，不再通过点击留下持续选中高亮。
- 播放图标保持独立，用于开始任务；悬停仍提示“开始”。
- 保存、空名称拦截、活动说明、关闭丢弃草稿、删除确认继续沿用 [直接编辑规则](BOOK-B-DIRECT-EDIT.md)。

修改源组件 87:1236，并同步 60 个任务行实例。悬停使用 MOUSE_ENTER / MOUSE_LEAVE 原生变量动作，仅改变对应高亮层；不导航、不修改任务数据。点击与返回列表重置悬停值。
