## 交互

- 书签组件 49:360：四种 Active 变体，每种仅一个高亮。三个未选中入口可点击切换，合计 12 条 CHANGE_TO 连线；只演示导航高亮，不扩展任务、日历和设置页面。
- 开始、25 分钟、当前条件、换一件、自己选：各有 Default / Hover / Pressed 三种变体，放入主界面及总览的实例保持组件关联。
- Hover 提亮或显示浅色底；Pressed 收紧阴影、压暗材质并使内容下沉 2 px。通过 ON_HOVER / ON_PRESS 的临时切换表达反馈。
- 控件本轮演示视觉反馈；开始计时、时间选择、条件筛选和手选等业务行为以已有产品流程为准。
