## 已有流程与可选增量

| 操作 | 当前原型的变化 |
| --- | --- |
| 时间入口 | 展开原有 5/10/15/30/60 与自定义；选择后回原推荐卡 |
| 当前条件 | 四个条件独立勾选，不离开当前弹层 |
| 下一步编辑 | 推荐卡不再显示“⋯”；活动列表管理入口保留原编辑器；结束后可在首页就地更新刚完成活动的说明，支持清空草稿、保存 / 取消 |
| 换一件 | 示例从读书换到画画；本轮用完进入“这轮先到这里”，可手选或重新看看 |
| 开始 | 直接进入现有计时页；可暂停、继续、展开说明 |
| 导航至活动列表 | 演示原有浮窗，点击浮窗返回计时 |
| 结束 | 保持现有行为：记录后回首页，显示记录提示 |
| 计时恢复 | 继续本次、结束记录或直接放弃；放弃后首页底部提示 30 秒，不计入今天 |
| 我的活动 | 列表、折叠详情、添加名称错误与填写示例；依用户批注取消搜索与添加说明 |
| 今天 | 同活动分组、展开每次时间段、查看记录明细 |
| 设置 | 原深浅色、语言和备份入口；文件操作只标示演示边界 |
| 续做说明 | 计时结束直接回新推荐首页；记下一步展开就地输入，可清空原文、重写、保存或取消；全程能开始下一项 |

预设状态用于表达现有软件的交互。新增提示仅为设计提案，不连接真实记录或计时服务。手机页为现有布局参考，主要交互按桌面版展示。
