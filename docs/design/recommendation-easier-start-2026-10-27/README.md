# 推荐页概念预览

2026-10-27，独立概念稿，使用示例活动。没有修改正式应用、用户数据、计时规则或已发布安装包。

- 左侧：展示下一步编辑状态，输入框右下方使用明显的绿色「保存」按钮，旁边保留「取消」。编辑时隐藏开始与换一件；保存后回到推荐。
- 右侧：更多菜单只保留「修改下一步」。鼠标移到三个点即可展开，移出菜单关闭；进入菜单途中有短暂过渡，避免间隙导致误关。
- 预览中的时间、当前条件也采用悬停展开和移出关闭；触屏保留点按，键盘保留 Enter、方向键和 Escape 操作。
- 演示中的「换一件」会跳过本轮已出现的活动；全部换过后提供自主选择的出口。
- 演示状态只在当前页面内存中保存；不读取或写入 localStorage，跨次保存尚未实现。正式应用已支持保存下一步；跨轮次暂停推荐按用户要求移除。

打开 `index.html` 可操作预览，`preview.png` 是双状态产品图。运行 `node docs/design/recommendation-easier-start-2026-10-27/render.cjs` 可重新渲染。
