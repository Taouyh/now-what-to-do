# 计时中断与恢复概念预览

日期：2026-10-27。独立产品图与可点击概念稿，不读取或保存真实活动及计时数据。后续已按此稿实现正式应用，验收见 [计时恢复验收](../../timer-recovery-validation.md)。

- 状态一：本轮到点停住，等待期间不累计。用户选择继续或结束并记录。
- 状态二：正常关闭后重新打开，恢复已保存进度，等待用户主动继续本次。离开期间不计入有效用时和暂停时间。
- 状态三：长暂停后保留上次的用时；接着做时记录上一段，并开启新一段。示例为昨天 20:40–20:48 的 8 分钟。

按钮可演示继续、暂停、结束和重置。演示画面使用固定数值，不运行真实计时器；到点继续采用既有 15 分钟计划对应追加 8 分钟的示例，长暂停重新开始用 15 分钟示例。长暂停的阈值、旧异常数据的确认方式、退出及异常中断时的保存机制仍待正式方案确认。
