# 今天页活动汇总提案

逐次记录的交互已进一步简化，当前实现参见 `../today-records-simple/README.md`。此目录保留初次分组设计，原内层折叠详情已由单行记录及省略号更多信息取代。

2026-10-25。用户已选定右侧的活动汇总形式，要求只保留汇总，不增加“按时间 / 按活动汇总”切换按钮，也不加入左侧说明文案。该方案已接入应用源码。此目录的 index.html 和 preview.png 使用合成数据，展示收起与展开两种状态；截图参数 capture=1 仅冻结预览的自动收起以便阅读。

今天页固定按活动汇总。组间按首次执行的开始时间升序排列，组内按每次开始时间升序排列。活动行显示最早开始时间、重复执行次数及有效用时之和；展开后显示每次执行的时间及有效时长，进一步展开单次记录后显示原有字段。

实现以 taskId 识别同一活动，同名的不同活动分别显示。只对今天筛选后的记录分组，不把跨活动间隔、暂停或计划时长计入汇总有效用时；原始记录独立保留。截图中的开始到结束时间与有效用时沿用示例记录口径，各自显示，不通过时间差反推已保存的有效时长。

活动卡片及逐次详情展开后 10 秒自动收起。打开内层详情会重置外层计时，保证有完整阅读时间；外层收起会关闭内层详情并清理计时，重开恢复折叠状态。离开今天或重新渲染时清理所有详情计时器。没有修改原始记录或增加存储字段。

重新生成图片：`node docs/design/today-activity-grouping/render.cjs`。使用独立临时 Chrome 配置，不读取应用数据或日常浏览器配置。
