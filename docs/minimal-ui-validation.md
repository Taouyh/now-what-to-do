# 简约界面实现与验证

日期：2026-10-22。分支：`design/minimal-ui`，起点及 master：`4ed3aa165c4f37da066bdd4709ab06224c7fd15e`。开始时工作区干净。本轮只修改本地文件，没有 commit、push、reset 或部署。

## 已实现

- 按确认的暖色留白效果图实现首页：显示可编辑的时间和环境摘要，自动推荐一项活动，主操作为「开始」，次操作为「换一件」。展开条件时使用浮层；有多个候选时避免连续推荐同一项，只有一项时禁用更换并说明原因。切换页面、修改条件时保留仍然符合要求的推荐。
- 空库显示首次添加引导，填写名称即可保存第一项。默认时长不超过当前可用时间（最多 10 分钟），默认环境沿用当前显示的环境；按钮下方显示默认属性，点击可进入完整编辑。没有自动创建任何示例活动。
- 我的活动改为原生可展开列表，支持名称及说明搜索、时长／环境／电脑筛选。展开后提供开始、编辑、删除。编辑后保留展开位置。
- 今天使用简洁汇总和记录列表，按列表显示的开始时间从早到晚展示（缺失开始时间时沿用结束或完成时间），不修改底层记录顺序。展开保留原始计划、开始／结束时间、实际有效用时、追加与暂停信息；缺失的旧时间仍明确显示未记录。
- 计时页面保留「暂停／结束」两个按钮。结束经确认后保存实际有效用时，放弃可不保存；长期活动继续保留。现有自动追加计时、刷新恢复、悬浮计时和防重复记账机制继续保留。
- 添加／编辑表单默认只展开名称与时长，条件和说明按需展开。提供 Escape 关闭、对话框内 Tab 循环、打开／关闭时的焦点处理；完整计时时底层页面不接收键盘焦点，顶部导航仍可切换为悬浮计时。
- 独立设置页面内选择浅色／深色、导出备份和导入恢复。恢复仍需确认整份替换；进行中的计时仍单独保存。

## 色彩与兼容

浅色背景 `#F7F5F0`，主按钮 `#5B6650`；深色背景 `#1E201C`，卡片 `#272A24`，文字 `#E9E6DC`，主按钮 `#C3CEA8`。

保留原存储键和 v2 数据结构，既有数据只在内存中兼容，不因启动或看页面回写。旧目标及未知扩展字段保留。新安装的初始条件为 15 分钟、安静、无电脑；已有安装继续使用已保存的条件。

自定义可用时间仍只在当前会话使用，不写入原有预设偏好格式。已有用户不再需要每次打开网页重新选择两个条件；界面直接显示正在使用的已保存条件。
