# 推荐页下一步与右侧悬停菜单验收

日期：2026-10-27。根据确认的产品概念修改正式应用；本文记录推荐页实现阶段的本地验证，功能已纳入 1.3.0 发布内容。

## 行为

- 推荐卡可选显示「下一步」。三个点菜单可修改；编辑框右下方为绿色「保存」，旁边为「取消」。编辑期间隐藏开始与换一件；保存成功后返回推荐，取消不写入数据。输入最多 200 个字符，可清空。
- 「换一件」只排除当前这一轮的活动，不写入偏好、不创建历史。换完后提供自己选择及重新看看。更改已保存的时间或条件、完成一次活动、导入备份、点击重新看看或重新打开页面，会开启新一轮。最近做过的活动仍可推荐。
- 按用户确认移除跨轮次的「这阵子先不推荐」及恢复入口。推荐菜单只保留「修改下一步」，我的活动菜单保留「编辑」「删除」；跳过活动统一使用「换一件」。
- 推荐页与活动列表的三个点支持鼠标悬停展开。菜单优先位于入口右侧，空间不足时改到左侧或限制在可见屏幕内；菜单顶部与入口对齐，底部空间不足时向上调整。
- 从入口移入菜单有 160 毫秒过渡，避免跨越间隙时误关；移出菜单立即关闭。鼠标悬停不抢焦点。Escape、Tab、外部点按、页面切换和对话框操作可关闭菜单。移除对话框产生的鼠标进入事件不会在静止鼠标下重新打开菜单。
- 手机仍可点按；键盘保留 Enter、上下方向键、Home、End、Tab 与 Escape。时间和当前条件继续使用原有悬停操作。

## 数据与范围

活动新增可选字段 `nextStep`（字符串，最多 200 字符）。沿用 v2 备份结构，保留旧字段、未知字段、说明和历史。读取旧数据不自动写回；下一步可随导出、导入和重载恢复，始终按用户原文显示。此前试用保存的 `recommendationPaused` 字段作为未知元数据保留，但不再参与推荐，因此原先排除的活动会重新参与推荐。

保存失败时保留编辑草稿并回滚活动数据；推荐页操作不修改正在运行或暂停的计时。后续计时累计、退出恢复与到点等待的修复，见 [计时恢复验收](timer-recovery-validation.md)。
