# Now What 1.3.0

A clearer next step and a timer that waits for you when you come back.

## What's new

- Add an optional next step right on the recommendation card. Edit it from **⋯**, with clear **Save** and **Cancel** actions.
- **Try another** skips an activity for this round. When the round is exhausted, choose for yourself or look again. Recent practice no longer reduces an activity's recommendation chance.
- Hover over **⋯** on a recommendation or any activity row to open its menu. Menus prefer the right side and stay inside narrow screens. Touch and keyboard controls remain available.
- A round stops at zero. Only choosing **Continue** adds more time; waiting never keeps adding effective time.
- Closing and reopening shows saved progress and waits for an explicit choice. Time away is excluded. A pause of one hour or more keeps the previous time as a separate session when you start again.
- Windows saves a checkpoint before its window closes and handles sleep notifications. Android includes background, screen-off and resume hooks. Unexpected termination recovers the last successful checkpoint, normally saved every five seconds while running.
- English, Chinese and Japanese READMEs and the product site include current screenshots and downloads.

## Downloads and upgrades

- **Windows 10 / 11, x64:** `Now-What-1.3.0-Windows-x64-Setup.exe`, about 2 MiB. Uses the system WebView2 runtime; setup downloads it if missing. Installer is unsigned.
- **Android 7.0+:** `Now-What-1.3.0-Android.apk`. Same package and signing identity, versionCode 5. Install over the existing app without uninstalling first.
- **Web:** [Open Now What](https://taouyh.github.io/now-what-to-do/).
- `SHA256SUMS.txt` contains checksums for both installation packages.

Update from 1.1 / 1.2 by installing over the existing app. Data locations and the v2 backup format are unchanged. Before upgrading from **Windows 1.0**, export a backup in the old app and restore it in the new app's Settings. A running timer is not included in backups.

**An older unfinished timer may ask for its actual duration.** Older running timers have no reliable periodic checkpoint, so the app does not guess from the time away. Confirm the time you spent, or explicitly discard that session. Existing completed records are not rewritten, and the old timer snapshot is retained with a confirmed recovery record.

Android package compilation, signing and contents are checked. Real-phone runtime and operating-system recovery remain unverified.

## Validation

128 automated tests and 42 timer/interface browser scenarios pass in the implementation validation. Windows native window closing, running and paused recovery, backups, imports and minimized timing pass with an isolated profile. Android lifecycle code compiles against Android 35 with JDK 17. Release checks also verify installation package contents, versioned download links, signing and checksums. Android real-device testing remains pending.
