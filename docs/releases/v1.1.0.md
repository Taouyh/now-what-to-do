# Now What 1.1.0

Finish one session and keep going: **End** saves your actual time immediately, returns Home and suggests a different activity whenever one fits your current conditions. No end confirmation, history redirect or mandatory add form.

## Download

- **Windows 10 / 11, x64:** `Now-What-1.1.0-Windows-x64-Setup.exe` (~2 MiB). New C++ / Win32 shell with the system Microsoft Edge WebView2 Runtime; no bundled Electron, Node.js or .NET. Setup lets you choose the directory and downloads Microsoft's signed runtime installer only when the runtime is missing. After setup the app works offline.
- **Android 7.0+:** `Now-What-1.1.0-Android.apk`. Same package ID and signing key as 1.0; versionCode 2. Install over the old version without uninstalling.
- **Web:** [Open Now What](https://taouyh.github.io/now-what-to-do/). The URL is unchanged.
- `SHA256SUMS.txt` contains hashes for both installers.

Installed apps start in English. Chinese and Japanese are available in Settings. The product name stays **Now What** in all three languages.

## Windows memory and size

On the same Windows machine with the same UI, clean synthetic profiles and a short idle period after language switching, total private memory was **188 MiB for Electron vs 124 MiB for the C++ / WebView2 shell** (about 34% lower in that snapshot). Working-set sums were 348 vs 316 MiB. This includes the native host and browser subprocesses. Download size drops from about 107 MiB to about 2 MiB; this excludes the shared WebView2 Runtime.

These are measurements, not a RAM limit or a guarantee on other machines. Window state, audio, data, runtime version and debugging affect memory; working-set totals can double-count shared pages. Inactive windows request WebView2's low-memory target while keeping scripts and the timer running. [Build and measurement details](https://github.com/Taouyh/now-what-to-do/blob/design/minimal-ui/docs/installable-builds.md#windows-memory).

## Upgrading from Windows 1.0

1. Finish the running session in the old app, then use **Settings → Back up data → Export**.
2. Install 1.1, open Settings and restore that JSON backup. Check activities and history before removing the old version.
3. The shells use different browser stores. There is **no automatic data migration**; old data is preserved. A running timer is not included in a backup. The [1.0 release](https://github.com/Taouyh/now-what-to-do/releases/tag/v1.0.0) remains available if you need to reopen it to export.

The new profile is `%LOCALAPPDATA%\NowWhat\WebView2`. Uninstalling 1.1 preserves this profile. Web, desktop and Android data do not automatically sync. Export backups before uninstalling or clearing data. Old and new Windows shortcuts share a name; if uninstalling the old version removes a shortcut, reinstall 1.1 to restore it.

## Validation and limits

- 104 Node unit tests pass, with browser checks for the session-ending flow.
- Hidden native app tests cover English default, all three languages, safe native backup export, real file-input import, minimized timer progress, restart persistence and the next recommendation after End.
- Actual installer/uninstaller tested in an isolated directory with spaces; unrelated files and app profiles are preserved. Package contents match source; Android signing and application labels verified.
- Windows EXE is unsigned and may show an unknown-publisher notice. Windows installation was tested with WebView2 already present; missing-runtime installation is not yet verified in a clean VM. Android installation/runtime is not yet verified on a real phone or emulator.
