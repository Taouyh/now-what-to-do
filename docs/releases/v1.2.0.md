# Now What 1.2.0

Today now brings repeated sessions together under each activity, so you can see what you did and the time you spent without a long list of duplicate cards.

- Expand an activity to see simple rows: time range, actual duration and **⋯** for more information.
- Exact timestamps, the original plan, added time and pauses are available on demand. Zero added time and pauses are hidden; short sessions retain seconds, and cross-date records remain explicit.
- Activity cards close after ten seconds. Opening more information restarts the countdown; Escape closes it and returns keyboard focus.
- Existing execution records, activity identities, duration calculations and stored data are preserved. Activities and individual sessions remain in ascending start-time order.
- The English, Chinese and Japanese READMEs and product site include current screenshots and updated downloads.

## Downloads and upgrades

Windows uses the existing C++ / WebView2 shell; Android uses the same package name and signing identity with versionCode 3. Update from 1.1 by installing over the existing app. The data locations and local storage format have not changed.

For Windows 1.0, finish any running timer and export a backup from the old app before installing the current version, then restore it in Settings. The 1.0 Electron shell uses a different data location. Old releases remain available.

Both packages support English, Chinese and Japanese and start in English. Windows is unsigned; Android installation and runtime have not been verified on a real phone or emulator. Release assets include SHA-256 checksums.

## Validation

109 Node tests pass. Today's browser scenarios pass through both local-file and HTTP entry points, with additional localization and interface regressions. The product site passes three-language checks at seven viewport widths, image switching, video playback and existing-data preservation.

The Windows native app passes isolated backup, import, minimized-timer and restart checks. The installer and uninstaller pass in a separate directory. Both packages contain the current app source; Android version 1.2.0 / versionCode 3 verifies with the same certificate as 1.1.0.
