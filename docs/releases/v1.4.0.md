# Now What 1.4.0 — Book edition

Your activities now live in an open book: warm paper, bookmark navigation, a two-page task library, and a journal of your time.

- Keep an activity and an optional next step. Choose your time and conditions, then start one feasible activity.
- Pause, resume, and finish a session. Reopening waits for your choice before resuming.
- Leave a note for next time and review recorded sessions in the Journal.
- Keep light/dark themes, English/Chinese/Japanese, local storage, and backup/restore.
- New English introduction page and 77-second product demo with soft music and distinct mouse clicks; no voiceover or decorative guiding lines.

Windows uses the shared system WebView2 runtime; Android uses the system WebView. Neither package bundles Electron or a full browser. Six textures use lossless WebP with verified identical visible pixels. Fonts and offline language coverage are preserved. The marketing video is only on the website, not in installed apps.

## Updating and data

Export a backup in Settings first. Install over 1.1–1.3 without uninstalling. Android retains its package name and release signing key, with versionCode 6. Windows retains its profile path and `https://nowwhat.local` storage origin. The browser app stays at the same GitHub Pages URL and origin.

Windows 1.0 users must export from the old app and restore in the new one. Restore replaces current data. Backups do not include a running timer.

The Windows installer is unsigned. First setup needs internet if WebView2 is missing. Android needs a current WebView; APK build and signature checks do not establish real-phone acceptance. No real-phone or participant testing is claimed for this release.

## Rollback

Keep a backup before updating. Earlier installers remain under [Releases](https://github.com/Taouyh/now-what-to-do/releases). Android cannot normally downgrade versionCode without uninstalling, which deletes local data; export before any downgrade. For web rollback, publish a reviewed earlier source through the `master` workflow. Do not delete browser storage or change the site origin.

Release verification and artifact hashes are recorded in [the deployment report](../deployment/book-1.4.0/RELEASE.md).
