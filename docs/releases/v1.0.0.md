# Now What? 1.0.0

Got a little free time? Pick something you've been meaning to do, and start now.

- **Windows:** download `Now-What-1.0.0-Windows-x64-Setup.exe` (Windows 10/11, 64-bit). Choose your installation folder in the installer.
- **Android:** download `Now-What-1.0.0-Android.apk` (Android 7.0+ with an up-to-date Android System WebView).
- Both apps work offline and start in **English** on first use. Choose English, 简体中文 or 日本語 in Settings; your choice is remembered.
- Data stays on your device. Use Settings to export or restore a backup when moving between the website and installed apps.

The Windows app has passed desktop checks. Windows may show an unknown-publisher notice because the installer has no publisher certificate. The APK signature and packaged files have been verified; Android phone testing is still pending. Background timers on Android are not reliable alarms.

`SHA256SUMS.txt` contains checksums for both installers. Use the EXE or APK above; GitHub's “Source code” downloads contain the project files.
