# Now What 1.2.1

Choose your time and conditions with one less click, then start something you've been meaning to do.

- On desktop, hover over the time or **Current conditions** to open its menu. Crossing into the panel keeps it open; leaving the panel closes it immediately. Touch and keyboard controls remain available.
- Current conditions use four simple checkboxes, all unchecked on first use. Your choices are remembered.
- Time options remain 5, 10, 15, 30, 60 minutes and custom. Sessions continue to use a chosen duration.
- The three-language READMEs now open with the app icon, a short introduction, navigation, badges and current screenshots. The product site explains the new interaction and shows the app in each language.

## Download and update

- **Windows 10 / 11, x64:** `Now-What-1.2.1-Windows-x64-Setup.exe`, about 2 MiB. Uses the system WebView2 runtime; setup downloads it if missing. Installer is unsigned.
- **Android 7.0+:** `Now-What-1.2.1-Android.apk`. Same package and signing identity, versionCode 4. Install over the existing app without uninstalling first. Runtime has not yet been tested on a real phone.
- **Web:** [Open Now What](https://taouyh.github.io/now-what-to-do/).
- `SHA256SUMS.txt` contains checksums for both installers.

Update from 1.1 / 1.2 by installing over the existing app. Data locations and storage format are unchanged. Before upgrading from **Windows 1.0**, export a backup from the old app and restore it in the new app's Settings. A running timer is not included in backups.

## Validation

- 109 automated tests pass, alongside 12 current-condition browser scenarios and 23 interface regression scenarios for the hover interaction.
- The product page passes English, Chinese and Japanese checks at seven viewport widths, language-specific screenshots, video playback and existing-data preservation.
- The Windows app passes isolated backup, import, minimized timing and restart checks. Its installer and uninstaller pass in a separate test directory.
- Both installation packages contain the current source. Android 1.2.1 / versionCode 4 verifies with the existing signing identity. Real Android device testing remains pending.
