# Now What 1.4.1 — Your activities, in your order

Windows, Android and the browser app now share the latest book interface.

- Pin frequently used activities. Drag a grip to reorder within pinned or unpinned groups; hover Previous/Next during a drag to move between pages. Arrow keys on the grip also reorder activities.
- Task pagination fits the available space. Mobile layouts improve settings visibility and the activity editor when the keyboard opens.
- Activity descriptions open by default. Continuation notes use paper slips, with consistent action buttons throughout the app.
- The introduction website supports English, Chinese and Japanese. It starts in English; hover the language control to show choices. Download links lead to this project's GitHub Releases.
- New 86-second English demo includes pinning and real drag interactions, with soft original music and click sounds, no voiceover. It is an edited screenshot-based walkthrough, not a real-time recording.

## Updating

Export a backup first, then install over the existing app without uninstalling. Windows keeps its profile and storage origin; Android keeps its package ID/signing certificate and increases versionCode to 7. Version-2 backups remain compatible, with optional pin and manual-order fields. Windows 1.0 needs manual export/import. Backups do not include an active timer.

Windows is unsigned and may display an unknown-publisher notice. WebView2 is shared with the system; first installation needs internet if it is missing. Android requires Android 7+ and a current WebView. Installed apps work offline.

Independent Windows install, synthetic 1.4.0 upgrade, ordering, backup/restore, restart and uninstall-preservation checks passed. Android signing/alignment/content checks passed; automated tests did not execute on an Android device. The project owner confirmed the delivered native candidates before authorizing this release. This is not a claim of exhaustive device coverage.

Native artifact hashes and test limits: [1.4.1 verification](../deployment/native-1.4.1-2026-11-09/INDEPENDENT-TEST.md). Earlier installers remain available in Releases. Android cannot normally downgrade versionCode in place; preserve a backup before any uninstall or rollback.
